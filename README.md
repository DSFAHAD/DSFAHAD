## 🚀 Featured Projects

### 🏠 [Zameen Real Estate Price Prediction](https://github.com/DSFAHAD/zameen-real-estate-price-prediction)
End-to-end pipeline that scrapes live property listings from Zameen.com (Pakistan's largest real estate portal), then cleans, analyzes, and models the data to predict house prices in Lahore.
`Python` · `Web Scraping` · `Scikit-learn` — core focus is the scraping pipeline against a real, actively-defended commercial site.

### 💳 [Credit Card Fraud Detection Pipeline](https://github.com/DSFAHAD/decodelabs-2-fraud-detection-pipeline)
A machine learning pipeline for detecting fraudulent transactions — data preprocessing, class-imbalance handling with SMOTE, model training, and evaluation via classification metrics.
`Python` · `Scikit-learn` · `SMOTE`

### 🛍️ [Customer Intelligence Platform](https://github.com/DSFAHAD/customer-intelligence-ML)
End-to-end customer analytics on the UCI Online Retail dataset — combines RFM analysis, PCA-based dimensionality reduction, clustering, and predictive modeling to turn transactions into customer segments and churn predictions.
`Python` · `Pandas` · `Scikit-learn` · `RFM` · `PCA` · `Clustering`

### 📦 [facrawlio](https://github.com/DSFAHAD/facrawlio) — published on [PyPI](https://pypi.org/project/facrawlio/)
A one-function web scraping library that pulls page data and saves it directly to CSV or JSON.
`Python` · `Web Scraping` · `Open Source Package`

### 🧰 [Smilo](https://github.com/DSFAHAD/Smilo-the-Python-Libraray) — published on [PyPI](https://pypi.org/project/smilo/)
A beginner-friendly Python library for data cleaning, dataset splitting, quick statistics, and visualization — built for lightweight data science workflows.
`Python` · `Open Source Package`

### 📊 [Loan Prediction: EDA & Feature Engineering](https://github.com/DSFAHAD/decodelab-1-Loan_prediction_EDA)
Transforms a raw, messy loan-applications dataset (614 applications, mixed numeric/categorical features, real missing values) into a clean dataset ready for machine learning.
`Python` · `Pandas` · `Feature Engineering`

### 📺 [YouTube Creator Performance Analysis](https://github.com/DSFAHAD/YouTube-creator-analysis)
EDA of Pakistani tech & education YouTube channels using the YouTube Data API v3 — examines views, engagement, and content length, plus a small regression model testing how predictable view counts are.
`Python` · `YouTube API` · `Regression`
