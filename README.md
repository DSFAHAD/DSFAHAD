## 🚀 Featured Projects

### 🏠 [Zameen.com Real Estate Scraper & Model](https://dsfahad.github.io/portfolio.fahad/)
Automated web scraping pipeline collecting **3,725 live listings**, paired with data cleaning and a Random Forest price prediction model (R² 0.53).
`Python` `Scikit-learn` `Web Scraping`

### 💳 [Credit Card Fraud Detection](https://dsfahad.github.io/portfolio.fahad/)
Classified highly imbalanced transaction data using SMOTE resampling, Logistic Regression, Random Forest, and GridSearchCV tuning.
`Python` `Scikit-learn` `SMOTE`

### 📊 [UK Retail RFM Customer Segmentation](https://github.com/DSFAHAD/UK-Retail-ML-linear-Reg)
RFM customer segmentation on **530K+ transaction records** to identify customer tiers and key revenue drivers.
`Python` `Pandas` `Linear Regression`

### 📺 [YouTube Creator Performance Analysis](https://github.com/DSFAHAD/YouTube-creator-analysis)
Analytics dashboard analyzing performance metrics and engagement patterns of top Pakistani Tech & Education channels via the YouTube API v3.
`Python` `YouTube API`

### 📦 [Smilo](https://github.com/DSFAHAD/Smilo-the-Python-Libraray)
Beginner-friendly Python library for data cleaning, dataset splitting, statistics, and quick visualization — built for data science workflows. Published on [PyPI](https://pypi.org/project/smilo/).
