### Rozee.pk Job Market Pipeline
![Live dashboard](https://img.shields.io/badge/Live%20dashboard-EADFC6?style=flat-square)

End-to-end data engineering pipeline that collects, cleans, validates, stores and visualizes Pakistan's tech job-market data. `Python` `PyPI` `Web scraping`

### Zameen.com Real Estate Scraper & Model
![3,725 scraped listings](https://img.shields.io/badge/3%2C725%20scraped%20listings-EADFC6?style=flat-square)

A resilient scraping pipeline for live property listings, feeding a price prediction model. `Python` `BeautifulSoup` `Scikit-learn`

**Outcome:** an original 3,725-listing dataset and a Random Forest regressor with R² of 0.53.

`Python` `K-Means` `PCA` `Scikit-learn`

**Outcome:** customer spend predicted with R² of 0.919 from basic behavioral signals.
